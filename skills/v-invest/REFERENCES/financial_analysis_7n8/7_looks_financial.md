# 七看财务分析

财务基本面深度分析，按顺序执行七个维度。

## 工作流程

### Step 1: 准备数据

```bash
# 基本信息
v-invest info {股票代码} -m {市场}

# 核心指标（5年历史）
v-invest indicator "roe,roa,gross_margin,net_profit_margin,debt_ratio,current_ratio" -s {股票代码} -m {市场} -y 5

# 财务报表
v-invest income {股票代码} -m {市场}
v-invest balance {股票代码} -m {市场}
v-invest cashflow {股票代码} -m {市场}
```

### Step 2: 按七看框架分析

逐一执行以下七个维度，每个维度输出明确结论。

---

## 1️⃣ 看营收数据

> 目标：评价盈利质量

### 数据获取

```bash
# 收入利润趋势
v-invest indicator "revenue,net_profit,net_profit_deducted,ocf" -s {股票代码} -m {市场} -y 5
```

### 分析要点

| 分析项 | 方法 | 关注点 |
|--------|------|--------|
| 收入趋势 | 5年收入变化 | 是否持续增长 |
| 利润趋势 | 净利润/扣非净利润对比 | 差值是否过大 |
| 现金流匹配 | 经营净现金流/归母净利润 | >1 为优秀 |
| 自由现金流 | OCF - CAPEX | 是否为正 |

### 输出要求

- 收入利润趋势图（标注异常点）
- 自由现金流计算结果
- 盈利质量评级：🟢优秀 / 🟡一般 / 🔴较差

---

## 2️⃣ 看成本费用构成

> 目标：识别核心成本影响因素

### 数据获取

```bash
# 毛利率与费用率
v-invest indicator "gross_margin,operating_margin,rd_ratio,sales_ratio,admin_ratio" -s {股票代码} -m {市场} -y 5
```

### 分析要点

| 分析项 | 方法 | 关注点 |
|--------|------|--------|
| 毛利率变化 | 历年趋势 | 成本管控能力 |
| 费用结构 | 研发/销售/管理费用率 | 投入方向是否符合战略 |
| 非经常性损益 | 占净利润比例 | 利润扰动程度 |

### 输出要求

- 成本结构拆解表
- 核心影响因素识别
- 费用投入方向评价

---

## 3️⃣ 看增长

> 目标：量化长期增长能力

### 数据获取

```bash
# 增长指标
v-invest indicator "revenue_growth,net_profit_growth" -s {股票代码} -m {市场} -y 5
```

### 分析要点

| 分析项 | 计算方法 | 评价标准 |
|--------|----------|----------|
| 收入CAGR | (末值/初值)^(1/n) - 1 | 与行业对比 |
| 利润CAGR | 同上 | 与收入增速对比 |
| 增长稳定性 | 增速波动程度 | 越稳定越好 |

### 输出要求

- 3年/5年复合增长率
- 与行业平均对比
- 增长能力评级

---

## 4️⃣ 看业务构成

> 目标：识别核心增长引擎

### 数据获取

```bash
# 财务报表中查看分部收入
v-invest income {股票代码} -m {市场}
```

### 分析要点

| 分析项 | 关注点 |
|--------|--------|
| 业务板块占比 | 各业务收入/利润占比 |
| 板块增长对比 | 核心增长/下滑来源 |
| 非主业收入 | 是否依赖副业利润 |

### 输出要求

- 业务构成饼图/表
- 核心增长引擎识别
- 业务聚焦度评价

---

## 5️⃣ 看资产负债

> 目标：判断资产健康度与债务风险

### 数据获取

```bash
# 资产负债指标
v-invest indicator "debt_ratio,current_ratio,quick_ratio,equity_ratio" -s {股票代码} -m {市场} -y 5

# 资产负债表
v-invest balance {股票代码} -m {市场}
```

### 分析要点

| 分析项 | 计算方法 | 评价标准 |
|--------|----------|----------|
| 资产轻重 | 非流动资产/总资产 | 行业对比 |
| 债务结构 | 有息/无息债务拆分 | 有息负债越低越好 |
| 资产负债率 | 总负债/总资产 | <60% 稳健 |
| 存货周转 | 存货周转天数 | 越短越好 |

### 输出要求

- 资产结构分析
- 债务风险评估
- 资产健康度评级

---

## 6️⃣ 看投入产出

> 目标：量化运营效率

### 数据获取

```bash
# 周转效率指标
v-invest indicator "asset_turnover,inventory_turnover,receivables_turnover" -s {股票代码} -m {市场} -y 5

# 资产负债表（计算WC）
v-invest balance {股票代码} -m {市场}
```

### 分析要点

| 分析项 | 计算方法 | 评价标准 |
|--------|----------|----------|
| 流动资金WC | 应收+预付+存货+合同资产-(应付+预收+合同负债) | 越低议价能力越强 |
| 1元收入占用WC | WC / 营业收入 | 越低越好 |
| 单位收入固定资产 | 固定资产 / 营业收入 | 轻资产优势 |
| 人均效率 | 营业收入/员工数 | 与同行对比 |

### 输出要求

- 运营效率指标表
- 上下游议价能力评价
- 投入产出效率评级

---

## 7️⃣ 看收益率

> 目标：综合判断盈利能力

### 数据获取

```bash
# 收益率指标
v-invest indicator "roe,roa,roic" -s {股票代码} -m {市场} -y 5
```

### 分析要点

| 指标 | 含义 | 优秀标准 |
|------|------|---------|
| ROE | 净资产收益率 | >15% |
| ROA | 总资产收益率 | >10% |
| ROIC | 投入资本回报率 | >12% |

### 输出要求

| 指标 | 数值 | 行业对比 | 评级 |
|------|------|---------|------|
| ROE | {x}% | {行业值} | 🟢/🟡/🔴 |
| ROA | {x}% | {行业值} | 🟢/🟡/🔴 |
| ROIC | {x}% | {行业值} | 🟢/🟡/🔴 |
