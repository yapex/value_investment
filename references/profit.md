# 利润表字段参考

## A股 (profit 命令)

数据格式：**宽格式**，每个财务项是一个列，返回 DataFrame。

### 基础列
| 列名 | 说明 |
|------|------|
| SECUCODE | 证券代码 (如 600519.SH) |
| SECURITY_CODE | 股票代码 |
| SECURITY_NAME_ABBR | 股票简称 |
| REPORT_DATE | 报告日期 |
| REPORT_TYPE | 报告类型 |

### 常用收入类列名
| 列名 | 说明 |
|------|------|
| TOTAL_OPERATE_INCOME | 营业总收入 |
| OPERATE_INCOME | 营业收入 |
| INTEREST_INCOME | 利息收入 |

### 常用成本类列名
| 列名 | 说明 |
|------|------|
| TOTAL_OPERATE_COST | 营业总成本 |
| OPERATE_COST | 营业成本 |
| SALES_EXPENSE | 销售费用 |
| MANAGE_EXPENSE | 管理费用 |
| FINANCE_EXPENSE | 财务费用 |
| RESEARCH_EXPENSE | 研发费用 |

### 常用利润类列名
| 列名 | 说明 |
|------|------|
| OPERATE_PROFIT | 营业利润 |
| TOTAL_PROFIT | 利润总额 |
| INCOME_TAX | 所得税费用 |
| NET_PROFIT | 净利润 |
| PARENT_NET_PROFIT | 归属母公司所有者的净利润 |
| MINORITY_INTEREST | 少数股东损益 |

### 常用每股列名
| 列名 | 说明 |
|------|------|
| BASIC_EPS | 基本每股收益 |
| DILUTED_EPS | 稀释每股收益 |

---

## 港股 (profit 命令)

数据格式：**长格式**，通过 STD_ITEM_NAME + AMOUNT 存储数据。

### 列说明
| 列名 | 说明 |
|------|------|
| SECUCODE | 证券代码 |
| SECURITY_CODE | 股票代码 |
| REPORT_DATE | 报告日期 |
| STD_ITEM_NAME | 项目名称 (用于筛选) |
| AMOUNT | 金额 |

### 常用收入类项目名
| STD_ITEM_NAME |
|---------------|
| 营业额 |
| 营运收入 |
| 其他营业收入 |
| 其他收入 |
| 利息收入 |

### 常用成本类项目名
| STD_ITEM_NAME |
|---------------|
| 营运支出 |
| 销售及分销费用 |
| 行政开支 |
| 融资成本 |

### 常用利润类项目名
| STD_ITEM_NAME |
|---------------|
| 毛利 |
| 经营溢利 |
| 除税前溢利 |
| 税项 |
| 除税后溢利 |
| 股东应占溢利 |
| 少数股东损益 |
| 持续经营业务税后利润 |
| 全面收益总额 |

### 常用每股项目名
| STD_ITEM_NAME |
|---------------|
| 每股基本盈利 |
| 每股摊薄盈利 |
| 每股股息 |

---

## 美股 (profit 命令)

数据格式：**长格式**，通过 ITEM_NAME + AMOUNT 存储数据。

### 列说明
| 列名 | 说明 |
|------|------|
| SECUCODE | 证券代码 |
| SECURITY_CODE | 股票代码 |
| REPORT_DATE | 报告日期 |
| ITEM_NAME | 项目名称 (用于筛选) |
| AMOUNT | 金额 |

### 常用收入类项目名
| ITEM_NAME |
|-----------|
| 营业收入 |
| 主营收入 |
| 利息收入 |
| 其他收入(支出) |

### 常用成本类项目名
| ITEM_NAME |
|-----------|
| 营业成本 |
| 主营成本 |
| 研发费用 |
| 营销费用 |
| 其他营业费用 |
| 营业费用 |
| 重组费用 |

### 常用利润类项目名
| ITEM_NAME |
|-----------|
| 毛利 |
| 营业利润 |
| 持续经营税前利润 |
| 所得税 |
| 持续经营净利润 |
| 净利润 |
| 归属于母公司股东净利润 |
| 归属于普通股股东净利润 |
| 全面收益总额 |

### 常用每股项目名
| ITEM_NAME |
|-----------|
| 基本每股收益-普通股 |
| 摊薄每股收益-普通股 |
| 每股股息-普通股 |
| 基本加权平均股数-普通股 |
| 摊薄加权平均股数-普通股 |
