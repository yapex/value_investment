# macOS Input Automation

## Overview

This domain covers automation techniques for macOS input methods, particularly for handling non-ASCII text like Chinese.

## Key Entry

- **macos_chinese_input_automation** — Documents a specific technique for automating Chinese text input on macOS using clipboard and keyboard navigation.

## Key Facts

- **Input Method**: Clipboard-based paste for Chinese text (keystroke command only supports ASCII)
- **Selection**: Arrow keys (up/down) navigate and select from search candidates
- **Workflow**: Copy Chinese text → Paste via clipboard → Select from search candidates using arrow keys

## Relationships

This automation approach is specific to macOS input methods and applies to any workflow requiring programmatic Chinese text entry.
