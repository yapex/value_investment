# roe_analysis

ROE 深度分析框架，15+ 指标 + 10年历史数据，全面评估股票质量。

---

## 核心原则

> ⚠️ **强制约束（违反会导致分析无效）**

- ✅ 所有数值必须来自 v-invest CLI 或 Python API 查询
- ✅ 表格中不能出现 `~`、`估`、`约` 等模糊表述
- ✅ 每个分析维度必须有明确的 🟢/🟡/🔴 评级
- ✅ 缺少数据时标记为"待查询"而非估算
- ✅ 必须包含行业基准对比（即使标注待查询）

---

## 数据获取

```bash
# 杜邦三要素 + 盈利能力（A 股示例）
v-invest indicator "roe,roa,net_profit_margin,gross_margin,total_assets_turnover,equity_multiplier" -s {股票代码} -m {市场} -y 10

# 运营效率
v-invest indicator "asset_turnover" -s {股票代码} -m {市场} -y 10

# 列出可用指标
v-invest indicators {市场}
```

---

## 分析框架

按顺序执行以下维度：

| 步骤 | 维度 | 核心产出 |
|------|------|---------|
| 1️⃣ | ROE 概览 | 当前值、10年均值、最高/最低 |
| 2️⃣ | 历史趋势 | 稳定性评估、变异系数、偏离度 |
| 3️⃣ | 杜邦拆解 | 净利润率、周转率、权益乘数 |
| 4️⃣ | 财务结构 | 资产负债率、流动比率 |
| 5️⃣ | 现金流 | 经营现金流/净利润 |
| 6️⃣ | 综合评级 | 汇总所有维度评级 |

## 1️⃣ ROE 概览

### 数据获取

```bash
v-invest indicator "roe,roe_weighted" -s {股票代码} -m {市场} -y 10
```

### 分析要点

| 评估项 | 方法 | 优秀标准 |
|--------|------|---------|
| 当前 ROE | 最新年份数值 | >15% |
| 10年平均 ROE | 均值 | >15% |
| 10年最高/最低 | 极值 | 越高越好 |

### 输出要求

```markdown

| 指标 | 数值 | 行业基准 | 评级 |
|------|------|---------|------|
| 当前 ROE | {x}% | 12-15% | 🟢顶尖 |
| 10年平均 ROE | {x}% | 10-12% | 🟢顶尖 |
| 10年最高 | {x}% | - | - |
| 10年最低 | {x}% | - | - |

**ROE 概览评级**：🟢优秀
```

## 3️⃣ 杜邦拆解

> ROE = 净利润率 × 总资产周转率 × 权益乘数

### 数据获取

```bash
v-invest indicator "net_profit_margin,gross_margin,total_assets_turnover,equity_multiplier" -s {股票代码} -m {市场} -y 10
```

### 分析要点

| 驱动类型 | 特征 | 代表企业 |
|----------|------|---------|
| 高净利率 | 茅台、苹果 | 品牌溢价 |
| 高周转率 | 沃尔玛、亚马逊 | 运营效率 |
| 高杠杆 | 金融、地产 | 财务杠杆 |

### 输出要求

```markdown
## 三、杜邦拆解

| 指标 | 2024 | 2023 | 行业平均 | 评级 |
|------|------|------|---------|------|
| 净利润率 | {x}% | {x}% | 15-20% | 🟢顶尖 |
| 总资产周转率 | {x} | {x} | 0.6-0.8 | 🟡一般 |
| 权益乘数 | {x} | {x} | 1.5-2.0 | 🟡一般 |

**驱动类型**：{利润驱动型 / 周转驱动型 / 杠杆驱动型}

**杜邦拆解评级**：🟢优秀
```

## 禁止模式

> ❌ 违反以下规则会导致输出无效

- ❌ 使用"~30%"等模糊表述 → 必须使用查询获取的精确值
- ❌ 缺少行业对比 → 必须包含行业基准（即使为待查询）
- ❌ 无评级 → 每个维度必须有 🟢/🟡/🔴 评级
- ❌ 占位符未替换 → 命令中不能有 `{股票代码}` 等占位符
- ❌ 只分析 1-2 年 → 必须包含 5-10 年历史数据
