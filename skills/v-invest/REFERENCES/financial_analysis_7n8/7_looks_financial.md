# 七看财务分析

财务基本面深度分析，按顺序执行七个维度。

## 核心原则

> ⚠️ **强制约束（违反会导致分析无效）**
> 
> - ✅ 所有数值必须来自 `v-invest indicator` 或 `v-invest income/balance/cashflow` 查询
> - ✅ 表格中不能出现 `~`、`估`、`约`、`大概` 等模糊表述
> - ✅ 每个维度结论必须包含 🟢/🟡/🔴 评级
> - ✅ 缺少数据时标记为"待查询"而非估算
> - ❌ 禁止使用 LLM 已有知识填充数据空白

### ⚠️ 违规检测规则

执行分析后，必须检查以下规则：

| 规则 | 检测方法 | 违规处理 |
|------|---------|---------|
| 模糊数据 | 搜索 `~`、`估`、`约`、`大概` | 立即修正为查询数据或标记"待查" |
| 年份连续性 | 检查表格年份是否连续 | 补充缺失年份，无数据则标注"待查询" |
| 评级完整性 | 检查每个维度是否有🟢/🟡/🔴 | 补充评级 |
| 数据完整性 | 检查表格是否包含所有必需列 | 补充缺失列 |
| 行业对比 | 检查是否包含行业基准 | 标注"待查询行业数据" |

# 现金流比率
# 经营现金流/净利润 > 1 为优秀
# 自由现金流/净利润 > 1 为优秀

### Step 1 (补充): 缺失指标手动计算

> ⚠️ 以下指标在 v-invest 中可能无法直接获取，需手动计算

```python
import pandas as pd
from value_investment import ValueInvestment

vi = ValueInvestment()

# 获取财务报表
df_income = vi.get_profit_sheet('{股票代码}', years=5)
df_income = df_income[df_income['end_type'] == '4'].sort_values('report_date')
df_income['year'] = pd.to_datetime(df_income['report_date'], format='%Y%m%d').dt.year

df_balance = vi.get_balance_sheet('{股票代码}', years=5)
df_balance = df_balance[df_balance['end_type'] == '4'].sort_values('report_date')
df_balance['year'] = pd.to_datetime(df_balance['report_date'], format='%Y%m%d').dt.year

df = df_income.merge(df_balance[['year', 'total_assets', 'total_liabilities', 'current_assets', 'current_liabilities', 'inventory', 'accounts_receivable']], on='year')

# ==================== 手动计算缺失指标 ====================

# 1. 资产负债率 = 总负债 / 总资产 × 100%
df['debt_ratio'] = df['total_liabilities'] / df['total_assets'] * 100

# 2. 流动比率 = 流动资产 / 流动负债
df['current_ratio'] = df['current_assets'] / df['current_liabilities']

# 3. 速动比率 = (流动资产 - 存货) / 流动负债
df['quick_ratio'] = (df['current_assets'] - df['inventory']) / df['current_liabilities']

# 4. 存货周转天数 = 365 / (营业成本 / 存货)
df['operating_cost'] = df['total_revenue'] - df['gross_profit']
df['inv_turnover'] = df['operating_cost'] / df['inventory']
df['inv_days'] = 365 / df['inv_turnover']

# 5. 应收账款周转天数 = 365 / (营业收入 / 应收账款)
df['ar_turnover'] = df['total_revenue'] / df['accounts_receivable'].fillna(1)
df['ar_days'] = 365 / df['ar_turnover']

# 6. ROIC = 税后营业利润 / 投入资本
# 投入资本 = 总资产 - 现金 - 无息负债
# 简化：ROIC ≈ EBIT / (总资产 - 现金 - 应付账款 - 预收款项)
# 或使用：ROIC = 净利润 / (股东权益 + 有息负债)
df['invested_capital'] = df['total_equity']  # 简化估算
df['roic'] = df['net_profit'] / df['invested_capital'] * 100  # 简化估算，更准确的应用 v-invest indicator "ROIC"

print(df[['year', 'debt_ratio', 'current_ratio', 'quick_ratio', 'inv_days', 'ar_days', 'roic']])  # 简化估算，更准确的应用 v-invest indicator "ROIC"
```

### 缺失指标速查表

| 指标 | 计算公式 | 数据来源 |
|------|---------|---------|
| 资产负债率 | 总负债 / 总资产 | 资产负债表 |
| 流动比率 | 流动资产 / 流动负债 | 资产负债表 |
| 速动比率 | (流动资产-存货) / 流动负债 | 资产负债表 |
| 存货周转天数 | 365 / (营业成本/存货) | 利润表+资产负债表 |
| 应收账款周转天数 | 365 / (营收/应收账款) | 利润表+资产负债表 |
| ROIC | 税后营业利润 / 投入资本 | ✅ 可用 `v-invest indicator "ROIC"` 直接获取 |

> ⚠️ **注意**：ROIC 可直接通过 `v-invest indicator "ROIC"` 获取，无需手动计算

## 5️⃣ 看资产负债

> 目标：判断资产健康度与债务风险

### 数据获取

```bash
# 资产负债指标（部分指标可能无法直接获取）
v-invest indicator "debt_ratio,current_ratio,quick_ratio,equity_ratio" -s {股票代码} -m {市场} -y 5

# 资产负债表
v-invest balance {股票代码} -m {市场}

# 存货周转天数计算（Python）
# 注意：部分平台的 inventory_turnover_days 指标可能无数据，需手动计算
python -c "
import pandas as pd
from value_investment import ValueInvestment
vi = ValueInvestment()

# 利润表
df_income = vi.get_profit_sheet('{股票代码}', years=5)
df_income = df_income[df_income['end_type'] == '4'].sort_values('report_date')
df_income['year'] = pd.to_datetime(df_income['report_date'], format='%Y%m%d').dt.year

# 资产负债表
df_balance = vi.get_balance_sheet('{股票代码}', years=5)
df_balance = df_balance[df_balance['end_type'] == '4'].sort_values('report_date')
df_balance['year'] = pd.to_datetime(df_balance['report_date'], format='%Y%m%d').dt.year

# 合并计算
df = df_income.merge(df_balance[['year', 'inventory']], on='year')
df['operating_cost'] = df['total_revenue'] - df['gross_profit']
df['inv_turnover'] = df['operating_cost'] / df['inventory']
df['inv_days'] = 365 / df['inv_turnover']
print(df[['year', 'inv_turnover', 'inv_days']])
"
```

### 分析要点

| 分析项 | 计算方法 | 评价标准 |

## 6️⃣ 看投入产出

> 目标：量化运营效率

### 数据获取

```bash
# 周转效率指标（包含新增指标）
v-invest indicator "asset_turnover,inventory_turnover,receivables_turnover,working_capital,wc_to_revenue" -s {股票代码} -m {市场} -y 5

# 注意：revenue_per_employee 需要员工人数数据，可通过以下方式获取：
# 1. tushare stock_company 接口
# 2. web search "{公司名} 员工人数"
```

### 分析要点

| 分析项 | 计算方法 | 评价标准 |
|--------|----------|----------|
| 流动资金WC | 应收+预付+存货+合同资产-(应付+预收+合同负债) | 越低议价能力越强 |
| 1元收入占用WC | WC / 营业收入 | 越低越好 |
| 单位收入固定资产 | 固定资产 / 营业收入 | 轻资产优势 |
| 人均效率 | 营业收入/员工数 | 与同行对比 |

### 指标说明

| 指标 | 计算公式 | 数据来源 | 说明 |
|------|---------|---------|------|
| working_capital | 应收+预付+存货+合同资产-(应付+预收+合同负债) | 资产负债表 | 自动计算 |
| wc_to_revenue | WC / 营业收入 | 资产负债表+利润表 | 自动计算 |
| revenue_per_employee | 营业收入 / 员工数 | 利润表+外部数据 | 需手动提供员工数 |

**注意：** revenue_per_employee 的员工人数不在标准财务报表中，可从以下渠道获取：
- tushare.pro stock_company 接口
- 同花顺/东方财富 F10 公司概况
- 年报附注"公司员工情况"
- web search "{公司名} 员工人数"
