# ROE 分析框架 - Agent 操作指南

> 本文档面向 AI Agent，指导如何调用 value_investment CLI 获取数据并完成 ROE 深度分析

---

## 一、任务目标

深度解读 ROE（净资产收益率）及其对业务的影响，识别高 ROE 背后的真实驱动因素与潜在风险。

**分析角色**: 资深财务分析师，精通财报数据、财务指标和业务的结合分析  
**输出格式**: Markdown 格式的详细分析和拆解流程

---

## 二、数据获取指令

### 2.1 快速分析所需指标（5个核心指标）

```bash
v-invest indicator \
  roe,roa,net_profit_margin,debt_ratio,total_assets_turnover \
  -s {stock_code} -y 5
```

**指标说明**:
| 指标 | 含义 | 优秀标准 |
|-----|------|---------|
| roe | 净资产收益率 | >20% |
| roa | 总资产收益率 | >15% |
| net_profit_margin | 净利润率 | >15% |
| debt_ratio | 资产负债率 | <50% |
| total_assets_turnover | 总资产周转率 | 因行业而异 |

### 2.2 深度分析所需指标（15+ 综合指标）

> **重要**: 支持获取 10 年历史数据（`-y 10`），用于长期趋势分析

**第一步：获取杜邦分析三要素 + 衍生指标（当前+历史）**

```bash
# 当前数据（最近1年）
v-invest indicator \
  roe,roa,net_profit_margin,gross_margin,total_assets_turnover,equity_multiplier,debt_ratio \
  -s {stock_code} -y 5

# 历史趋势数据（10年）
v-invest indicator \
  roe,net_profit_margin,total_assets_turnover,equity_multiplier \
  -s {stock_code} -y 10
```

**第二步：获取成长性指标**

```bash
v-invest indicator \
  roe_yoy,net_profit_yoy,total_revenue_yoy,operating_profit_yoy \
  -s {stock_code} -y 5
```

**第三步：获取运营效率指标**

```bash
v-invest indicator \
  inventory_turnover,receivable_turnover,current_ratio \
  -s {stock_code} -y 5
```

**第四步：获取现金流指标（如有）**

```bash
v-invest indicator \
  operating_cash_flow,ocf_to_netprofit \
  -s {stock_code} -y 5
```

**第五步：获取历史财务报表（10年）- 按需查询指定字段**

> **优化**: 使用 `-f` 参数指定字段，避免返回过多数据

```bash
# 历史利润表 - 仅查询关键字段
v-invest income {stock_code} -y 10 -f \
  report_date,total_revenue,operating_cost,gross_profit,operating_profit,net_profit

# 历史资产负债表 - 仅查询关键字段
v-invest balance {stock_code} -y 10 -f \
  report_date,total_assets,total_equity,total_liabilities,current_assets,current_liabilities

# 历史现金流量表 - 仅查询关键字段
v-invest cashflow {stock_code} -y 10 -f \
  report_date,operating_cash_flow,net_profit
```

**常用字段对照表**:

| 报表类型 | 常用字段 | 用途 |
|---------|---------|------|
| **利润表** | total_revenue, operating_cost, gross_profit, operating_profit, net_profit | 营收利润分析 |
| **利润表** | sales_expense, management_expense, rd_expenses, financial_expense | 费用结构分析 |
| **资产负债表** | total_assets, total_equity, total_liabilities | 资产负债分析 |
| **资产负债表** | current_assets, current_liabilities, inventory, accounts_receivable | 营运资本分析 |
| **现金流量表** | operating_cash_flow, net_profit | 现金流质量分析 |
| **现金流量表** | investing_cash_flow, financing_cash_flow | 投资融资分析 |

### 2.3 获取财务报表原始数据

```bash

# 利润表
v-invest income {stock_code} -y 5

```

### 2.4 获取股票基本信息

```bash

```

## 三、分析框架（按步骤执行）

### 步骤 1: ROE 基础解读

**数据需求**: roe, roa

**分析要点**:
1. **ROE 绝对值水平评估**
   - >20%: 优秀，具备较强股东回报能力
   - 15-20%: 良好，高于市场平均
   - 10-15%: 一般，处于市场平均
   - <10%: 较低，需关注盈利能力

2. **ROE 与 ROA 关系**
   - ROE ≈ ROA: 杠杆较低，主要靠资产盈利能力
   - ROE >> ROA: 杠杆较高，需关注财务风险

3. **与无风险收益率对比**（机会成本，约 3-4%）

4. **与行业平均水平对比**（Agent 需获取同业数据计算均值）
   - ROE > 行业均值: 优于行业
   - ROE = 行业均值: 行业平均
   - ROE < 行业均值: 低于行业

**行业均值获取方法**:
```bash
# 获取同业公司 ROE
v-invest indicator roe -s {peer_1} -y 5
v-invest indicator roe -s {peer_2} -y 5
v-invest indicator roe -s {peer_3} -y 5

# 计算行业均值
行业均值 = (peer_1_roe + peer_2_roe + peer_3_roe) / n
```

**输出要求**:
- 明确给出 ROE 水平评级（优秀/良好/一般/较差）
- 说明 ROE 与 ROA 的差异及原因
- **与行业均值对比，判断相对竞争力**

---

### 步骤 1.3: ROE 历史趋势分析（10年数据）

> **核心能力**: 利用 `-y 10` 获取 10 年历史数据，分析 ROE 稳定性和持续性

**数据获取**:
```bash
v-invest indicator roe -s {stock_code} -y 10
```

**分析维度**:

#### 1. ROE 稳定性评估

| 评估项 | 分析方法 | 优秀标准 |
|-------|---------|---------|
| **10年平均 ROE** | 计算 10 年 ROE 均值 | >15% 优秀 |
| **ROE 标准差** | 衡量波动性 | 越小越稳定 |
| **ROE 变异系数** | 标准差/均值 | <0.2 稳定 |
| **正收益年份占比** | ROE>0 的年份/10 | >90% 健康 |

**分析模板**:
```markdown
| 指标 | 数值 | 评价 |
|-----|------|------|
| 10年平均 ROE | {avg_roe}% | {评价} |
| ROE 最高值 | {max_roe}% | {年份} |
| ROE 最低值 | {min_roe}% | {年份} |
| 波动范围 | {range}% | {评价} |
| 正收益年份 | {n}/10 | {评价} |
```

#### 2. 穿越周期能力

**关键问题**:
- [ ] 经济下行期（如2020疫情、2022俄乌冲突）ROE 表现如何？
- [ ] 行业低谷期 ROE 是否保持正值？
- [ ] 与宏观经济指标（GDP增速）的相关性？

**分析方法**:
```markdown
| 时期 | 宏观环境 | ROE 表现 | 评价 |
|-----|---------|---------|------|
| 2020-2021 | 疫情冲击 | {roe}% | {抗风险能力} |
| 2022-2023 | 经济复苏 | {roe}% | {恢复能力} |
```

#### 3. ROE 均值回归检验

**核心问题**: 当前高 ROE 是否可持续？

**分析方法**:
- **趋势分析**: ROE 是上升、下降还是平稳？
- **均值回归**: 当前 ROE 与 10 年均值的偏离度
  - 偏离度 = (当前 ROE - 10 年均值) / 10 年均值
  - 偏离度 > 20%: 可能高估，需警惕回归
  - 偏离度 < -20%: 可能低估，关注改善

**输出模板**:
```markdown
**ROE 趋势判断**: {上升/下降/平稳}

**均值回归分析**:
- 当前 ROE: {current_roe}%
- 10 年均值: {avg_roe}%
- 偏离度: {deviation}%
- **结论**: {高于/低于/接近}历史均值，{可持续性判断}
```

### 步骤 2: 驱动因素分析（杜邦拆解）

> **增强**: 结合 10 年历史数据，分析三要素演变趋势

**核心公式**:
```
ROE = 净利润率 × 总资产周转率 × 权益乘数
```

**数据需求**: 
- 当前数据: net_profit_margin, total_assets_turnover, equity_multiplier, debt_ratio
- **历史数据（10年）**: roe, net_profit_margin, total_assets_turnover, equity_multiplier

**历史数据获取**:
```bash
v-invest indicator \
  roe,net_profit_margin,total_assets_turnover,equity_multiplier \
  -s {stock_code} -y 10
```

#### 2.1 净利润率驱动分析

**数据需求**: net_profit_margin, gross_margin

**分析框架**:
```
净利润率 = 毛利率 - 费用率 - 税率
         = 毛利率 - (销售费用+管理费用+研发费用)/营收 - 所得税/营收
```

**数据获取**:
```bash
# 从利润表获取费用数据 - 按需查询指定字段
v-invest income {stock_code} -y 5 -f \
  report_date,total_revenue,operating_cost,selling_expenses,admin_expenses,rd_expenses,income_tax

# 如需10年费用趋势数据
v-invest income {stock_code} -y 10 -f \
  report_date,total_revenue,selling_expenses,admin_expenses,rd_expenses
```

**费用率计算**:
| 费用类型 | 计算公式 | 分析重点 |
|---------|---------|---------|
| **销售费用率** | 销售费用 / 营收 | 营销效率、渠道控制力 |
| **管理费用率** | 管理费用 / 营收 | 管理效率、规模效应 |
| **研发费用率** | 研发费用 / 营收 | 创新能力、技术投入 |
| **所得税率** | 所得税 / 税前利润 | 税收优惠、税务筹划 |

**关键问题**:
- [ ] 毛利率是否高于行业平均？（品牌溢价？成本优势？）
- [ ] **费用率结构如何？哪项费用占比最高？**
- [ ] **税收影响多大？是否有税收优惠？**
- [ ] 费用率趋势如何？（规模效应是否显现？）
- [ ] 净利润率是否可持续？（竞争格局是否稳定？）

**行业参考**:
| 行业类型 | 净利润率特征 | 代表行业 |
|---------|-------------|---------|
| 高利润率 | >30% | 白酒、软件、医药 |
| 中利润率 | 10-30% | 制造业、消费 |
| 低利润率 | <10% | 零售、贸易、代工 |

#### 2.2 资产周转率驱动分析

**数据需求**: total_assets_turnover, inventory_turnover, receivable_turnover, fixed_assets_turnover

**数据获取**:
```bash
# 获取各项周转率指标（当前+历史）
v-invest indicator \
  total_assets_turnover,inventory_turnover,receivable_turnover,fixed_assets_turnover \
  -s {stock_code} -y 5

# 历史周转率趋势（10年）
v-invest indicator \
  total_assets_turnover,inventory_turnover,receivable_turnover \
  -s {stock_code} -y 10
```

**分析框架**:
```
总资产周转率 = 营业收入 / 平均总资产
```

**行业特性对照**:
| 行业类型 | 周转率特征 | 代表行业 |
|---------|-----------|---------|
| 高周转 | >1.5 | 零售、贸易 |
| 中周转 | 0.5-1.5 | 制造业 |
| 低周转 | <0.5 | 白酒、地产、重资产 |

**分项周转率分析**:

| 周转率类型 | 计算公式 | 分析重点 | 健康标准 |
|-----------|---------|---------|---------|
| **存货周转率** | 营业成本 / 平均存货 | 库存管理、产销平衡 | 因行业而异 |
| **应收账款周转率** | 营收 / 平均应收账款 | 回款能力、渠道控制力 | 越高越好 |
| **固定资产周转率** | 营收 / 平均固定资产 | 产能利用、资本密集度 | 因行业而异 |

**关键问题**:
- [ ] **存货周转**: 周转慢是主动备货还是滞销？是否伴随增值？
- [ ] **应收账款周转**: 回款周期长短？是否存在坏账风险？
- [ ] **固定资产周转**: 产能利用率如何？是否存在闲置资产？
- [ ] 总资产周转率低是行业特性还是管理问题？

#### 2.3 权益乘数驱动分析

**数据需求**: equity_multiplier, debt_ratio

**数据获取**:
```bash
# 当前杠杆水平
v-invest indicator equity_multiplier,debt_ratio -s {stock_code} -y 5

# 历史杠杆趋势（10年）
v-invest indicator equity_multiplier,debt_ratio -s {stock_code} -y 10
```

**计算公式**:
```
权益乘数 = 总资产 / 净资产 = 1 / (1 - 资产负债率)
```

**杠杆风险评估**:
| 权益乘数 | 杠杆水平 | 风险等级 |
|---------|---------|---------|
| <1.5 | 低杠杆 | 安全 |
| 1.5-2.5 | 适度杠杆 | 可控 |
| >2.5 | 高杠杆 | 警惕 |

**关键问题**:
- [ ] 杠杆水平是否与行业匹配？
- [ ] 负债结构是否合理（短债 vs 长债）？
- [ ] **杠杆趋势**: 是逐步加杠杆还是去杠杆？

### 步骤 2.4: 杜邦三要素演变分析（10年历史）

> **核心**: 分析 ROE 驱动因素的长期变化，识别竞争力演变

**数据需求**: 10 年杜邦三要素数据
```bash
v-invest indicator \
  roe,net_profit_margin,total_assets_turnover,equity_multiplier \
  -s {stock_code} -y 10
```

**分析框架**:

#### 1. 三要素趋势对比

**输出模板**:
```markdown
| 年份 | ROE | 净利润率 | 周转率 | 权益乘数 | 主要驱动 |
|-----|-----|---------|--------|---------|---------|
| 2024 | {roe}% | {npm}% | {ato} | {em} | {驱动因素} |
| 2023 | {roe}% | {npm}% | {ato} | {em} | {驱动因素} |
| ... | ... | ... | ... | ... | ... |
| 2015 | {roe}% | {npm}% | {ato} | {em} | {驱动因素} |

**趋势总结**:
- 净利润率: {上升/下降/平稳}，{原因分析}
- 周转率: {上升/下降/平稳}，{原因分析}
- 权益乘数: {上升/下降/平稳}，{原因分析}
```

#### 2. 驱动因素转变识别

**关键问题**:
- [ ] ROE 驱动因素是否发生变化？（如从周转驱动→利润驱动）
- [ ] 转变的原因是什么？（业务转型、竞争格局变化、战略调整）
- [ ] 当前驱动因素是否可持续？

**分析示例**:
```markdown
**茅台案例**:
- 2015-2020: ROE 主要由高净利润率驱动（品牌溢价）
- 2020-2024: 净利润率继续提升，周转率稳定，杠杆保持低位
- **结论**: 驱动因素稳定，竞争力持续增强

**某制造业案例**:
- 2015-2018: ROE 由周转率驱动（规模扩张期）
- 2019-2024: 周转率下降，转向净利润率驱动（产品升级）
- **结论**: 驱动因素转变，需评估新驱动因素的可持续性
```

#### 3. 关键转折点识别

**分析方法**:
- 识别 ROE 或三要素的突变点（同比变化 > 5%）
- 结合历史事件分析原因（政策、并购、危机等）

**输出模板**:
```markdown
| 时间 | 事件 | ROE变化 | 影响分析 |
|-----|------|--------|---------|
| 2020 | 疫情冲击 | -2% | 短期冲击，快速恢复 |
| 2018 | 政策调整 | +3% | 受益于供给侧改革 |
| 2015 | 并购扩张 | -1% | 整合期拖累，后期改善 |
```

### 步骤 3: 业务影响评估

> **增强**: 结合 10 年财务数据，分析成长轨迹和利润质量

**数据需求**: 
- 当前数据: roe_yoy, net_profit_yoy, total_revenue_yoy, operating_cash_flow
- **历史数据（10年）- 按需查询**: 
```bash
# 仅查询关键字段，避免数据量过大
v-invest income {stock_code} -y 10 -f \
  report_date,total_revenue,net_profit,operating_profit,gross_profit

v-invest cashflow {stock_code} -y 10 -f \
  report_date,operating_cash_flow,net_profit
```

#### 3.1 ROE 变化归因

**分析模板**:
```
ROE 变化 = Δ净利润率 + Δ周转率 + Δ杠杆
         = (业务盈利能力变化) + (运营效率变化) + (财务政策变化)
```

**关键问题**:
- [ ] ROE 上升主要来自哪个因素？
- [ ] 这种变化是暂时的还是结构性的？

#### 3.2 可持续性分析

**检查清单**:
- [ ] **竞争优势**: ROE 高是否来自护城河（品牌、成本、网络效应）？
- [ ] **周期性**: 行业是否处于周期顶点？
- [ ] **会计调节**: 是否有非经常性损益影响？
- [ ] **现金流匹配**: 利润是否有现金流支撑？

**关键指标**:
| 指标 | 健康标准 |
|-----|---------|
| 经营现金流/净利润 | >1 为优 |
| 自由现金流 | 持续为正 |

#### 3.3 成长轨迹分析（10年历史）

> **核心**: 利用 10 年利润表和现金流量表，分析成长质量和阶段

**数据获取**:
```bash
# 历史利润表（营收、利润趋势）
v-invest income {stock_code} -y 10 -f \
  total_revenue,net_profit,operating_profit,gross_profit

# 历史现金流量表（现金流质量）
v-invest cashflow {stock_code} -y 10 -f \
  operating_cash_flow,net_profit
```

**分析维度**:

##### 1. 营收增长轨迹

**输出模板**:
```markdown
| 阶段 | 时间 | 营收 CAGR | 增长特征 | 驱动因素 |
|-----|------|----------|---------|---------|
| 成熟期 | 2020-2024 | {cagr}% | 稳健增长 | {因素} |
| 成长期 | 2015-2019 | {cagr}% | 快速增长 | {因素} |
| 初创期 | 2010-2014 | {cagr}% | 爆发增长 | {因素} |

**增长阶段判断**: {成熟期/成长期/初创期}
```

**分析要点**:
- [ ] 营收增长是稳健还是爆发？
- [ ] 增长驱动来自内生还是外延（并购）？
- [ ] 当前处于什么增长阶段？

##### 2. 利润质量分析

**输出模板**:
```markdown
| 年份 | 净利润 | 经营现金流 | 净现比 | 利润质量 |
|-----|-------|-----------|--------|---------|
| 2024 | {np} | {ocf} | {ratio} | {评价} |
| 2023 | {np} | {ocf} | {ratio} | {评价} |
| ... | ... | ... | ... | ... |

**10年平均净现比**: {avg_ratio}
**利润质量评级**: {优秀/良好/一般/较差}
```

**分析标准**:
| 净现比 | 利润质量 | 说明 |
|-------|---------|------|
| >1.2 | 🟢 优秀 | 现金流充沛，利润扎实 |
| 0.8-1.2 | 🟡 良好 | 基本匹配，略有应收 |
| 0.5-0.8 | 🟠 一般 | 应收较高，需关注 |
| <0.5 | 🔴 较差 | 利润虚增，现金流差 |

##### 3. 成长质量综合评估

**关键问题**:
- [ ] 利润增长是否伴随现金流同步增长？
- [ ] 是否存在"增收不增利"或"增利不增现"？
- [ ] 成长是高质量（内生）还是低质量（并购）？

### 步骤 5: 风险提示

#### 5.1 高 ROE 陷阱识别

| 陷阱类型 | 识别信号 | 验证方法 |
|---------|---------|---------|
| 过度杠杆 | 权益乘数 > 3 | 检查 debt_ratio |
| 利润调节 | 现金流/利润 < 0.8 | 检查 ocf_to_netprofit |
| 周期顶点 | ROE 连续下滑 | 检查 roe_yoy |

#### 5.2 低 ROE 改善路径

**适用场景**: ROE < 10%，需提升股东回报

**改善路径（基于杜邦分析）**:

| 改善方向 | 具体措施 | 适用情况 | 风险提示 |
|---------|---------|---------|---------|
| **提升净利润率** | 提价、降本、优化费用 | 有定价权、成本优势 | 可能损失市场份额 |
| **提升周转率** | 去库存、加速回款、轻资产化 | 库存高、应收多、资产重 | 可能影响客户体验 |
| **适度加杠杆** | 增加负债、回购股票 | 负债率低、现金流稳 | 增加财务风险 |
| **剥离低效资产** | 出售亏损业务、关停低效产能 | 多元化过度、资产冗余 | 短期业绩承压 |

**改善优先级**:
1. **首选**: 提升净利润率（最可持续）
2. **次选**: 提升周转率（需平衡效率与服务）
3. **慎用**: 加杠杆（仅适合低负债公司）

#### 5.3 关键监控指标

| 风险指标 | 预警阈值 |
|---------|---------|
| ROE 下滑 | roe_yoy < -5% |
| 利润率下滑 | 连续 2 年下滑 |
| 杠杆上升 | equity_multiplier 同比上升 > 0.3 |
| 现金流恶化 | ocf_to_netprofit < 0.5 |
