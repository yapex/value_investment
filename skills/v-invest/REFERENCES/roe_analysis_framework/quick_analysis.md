# ROE 快速分析

5-6 个核心指标，快速判断股票质量。适合初步筛选。

## 工作流程

### Step 1: 获取核心指标

```bash
v-invest indicator "roe,roa,net_profit_margin,debt_ratio,total_assets_turnover" -s {股票代码} -m {市场} -y 5
```

### Step 2: 快速判断

根据数据快速评估：

1. **ROE > 20%**: 优秀
2. **ROE 15-20%**: 良好
3. **ROE 10-15%**: 一般
4. **ROE < 10%**: 较差

### Step 3: 输出结论

---

## 数据获取命令

```bash
# 5个核心指标，5年数据
v-invest indicator "roe,roa,net_profit_margin,debt_ratio,total_assets_turnover" -s 00700 -m HK -y 5

# 财务指标快照
v-invest finind 00700 -m HK
```

### 常用市场代码

| 市场 | 代码示例 | 参数 |
|:-----|:---------|:-----|
| A股 | 600519 | `-m A` |
| 港股 | 00700 | `-m HK` |
| 美股 | AAPL | `-m US` |

---

## 核心指标

| 指标 | 含义 | 优秀标准 |
|------|------|---------|
| roe | 净资产收益率 | >20% |
| roa | 总资产收益率 | >15% |
| net_profit_margin | 净利润率 | >15% |
| debt_ratio | 资产负债率 | <50% |
| total_assets_turnover | 总资产周转率 | 因行业而异 |

---

## 分析框架

### 1. ROE 基础评估

| ROE 区间 | 评价 |
|----------|------|
| >20% | 优秀 |
| 15-20% | 良好 |
| 10-15% | 一般 |
| <10% | 较差 |

### 2. ROE vs ROA

- **ROE ≈ ROA**: 杠杆低，靠资产盈利
- **ROE >> ROA**: 杠杆高，关注财务风险

### 3. 杜邦简化判断

| 驱动类型 | 特征 | 风险 |
|----------|------|------|
| 利润驱动 | 高净利率 | 需验证盈利质量 |
| 周转驱动 | 高周转率 | 需验证持续性 |
| 杠杆驱动 | 高权益乘数 | 关注债务风险 |
