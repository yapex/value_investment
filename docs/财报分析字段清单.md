# 财报分析字段清单

> **来源**：基于《手把手教你读财报精简工具版》整理
>
> 本文档将文档中计算所需的所有字段整理为清单，包含财务报表直接字段与衍生计算指标。
>
> **优先级说明**：
> - **P0（核心）**：财务报表基础数据，必须获取
> - **P1（重要）**：衍生指标计算所需，或财报附注中的关键数据
> - **P2（参考）**：辅助分析数据，需要时可取

## 四、需要计算的指标（衍生指标）

> **优先级说明**：
> - P1：核心指标，直接用于投资决策
> - P2：辅助指标，用于深入分析

### 4.1 流动性/偿债能力

| 优先级 | 指标 | 公式 | 说明 |
|:------:|------|------|------|
| P1 | **现金短债比** | (现金 + 可迅速变现金融资产) ÷ 有息负债 | >1 为安全 |
| P1 | **净利润含金量** | 经营现金流净额 ÷ 净利润 | 连续 >1 为优秀 |
| P2 | 现金短债比(保守) | (现金 + 可迅速变现金融资产) ÷ 一年内到期有息负债 | >1 为安全 |
| P2 | 有息负债率 | 有息负债 ÷ 总资产 | 与同行对比 |

### 4.2 盈利能力

| 优先级 | 指标 | 公式 | 说明 |
|:------:|------|------|------|
| P1 | **ROE（净资产收益率）** | 净利润 ÷ 平均净资产 | >15% 为优秀 |
| P1 | **毛利率** | (营业收入 - 营业成本) ÷ 营业收入 | 同行对比 |
| P1 | **净利率** | 净利润 ÷ 营业收入 | |
| P2 | **总资产收益率** | 净利润 ÷ 平均总资产 | |
| P2 | 营业利润率 | 营业利润 ÷ 营业收入 | |
| P2 | 费用率 | 三费 ÷ 营业总收入（含财务费用调整） | |
| P2 | 费用占毛利润比 | (销售费用 + 管理费用) ÷ (营业收入 - 营业成本) | <50% 优秀，<70% 良好 |
| P2 | 研发费用占比 | 研发费用 ÷ 营业收入 | |

### 4.3 营运能力

| 优先级 | 指标 | 公式 |
|:------:|------|------|
| P2 | 应收账款周转率 | 营业收入 ÷ 平均应收账款 |
| P2 | 固定资产周转率 | 营业收入 ÷ 固定资产净值 |
| P2 | 总资产周转率 | 营业收入 ÷ 平均总资产 |
| P2 | 存货周转率 | 营业成本 ÷ 平均存货 |

### 4.4 成长性

| 优先级 | 指标 | 公式 |
|:------:|------|------|
| P1 | 营业收入增长率 | (本期 - 上期) ÷ 上期 × 100% |
| P2 | 净利润增长率 | (本期 - 上期) ÷ 上期 × 100% |
| P2 | 营业利润增长率 | (本期 - 上期) ÷ 上期 × 100% |
| P2 | 总资产增长率 | (本期 - 上期) ÷ 上期 × 100% |
| P2 | 净资产增长率 | (本期 - 上期) ÷ 上期 × 100% |

### 4.5 资产质量

| 优先级 | 指标 | 公式 | 说明 |
|:------:|------|------|------|
| P2 | 应收款占营收比 | 应收账款 ÷ 营业收入 | >30% 需警惕 |
| P2 | 应收款占资产比 | (所有应收 - 银票) ÷ 总资产 | >30% 严重，>50% 有问题 |
| P2 | 月均营业收入 | 营业收入 ÷ 12 | 用于应收款分析 |

### 4.6 资产结构

| 优先级 | 指标 | 公式 | 说明 |
|:------:|------|------|------|
| P2 | 生产资产占比 | 生产资产 ÷ 总资产 | 决定轻重资产 |
| P2 | 生产资产回报率 | 税前利润总额 ÷ 生产资产 | >社会平均回报率为优 |

### 4.7 现金流质量

| 优先级 | 指标 | 公式 | 说明 |
|:------:|------|------|------|
| P2 | 折旧摊销覆盖比 | 折旧摊销 ÷ 经营现金流净额 | 越大越好 |

### 4.8 员工相关

| 优先级 | 指标 | 公式 |
|:------:|------|------|
| P2 | 员工平均薪酬 | 应付职工薪酬本期增加 ÷ 员工总数 |
| P2 | 工资黏性 | 人均工资上调至盈亏平衡的比例 |
