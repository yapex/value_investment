# 偏见校验

完成分析后，主动排查常见认知偏差，提示分析局限性。

## 偏见自查清单

完成分析后，逐项检查以下偏见：

### 1. 光环效应

> 没有因为单一优点全盘肯定/否定企业

**自查问题**：
- [ ] 是否因为某个亮点（如高ROE、知名品牌）而忽视了其他问题？
- [ ] 是否因为某个缺点而否定了整体价值？

**修正方法**：强制列出至少3个优点和3个缺点

---

### 2. 证实偏见

> 没有先入为主，已经纳入反面证据

**自查问题**：
- [ ] 是否在分析前已有预设结论？
- [ ] 是否主动寻找了反对自己观点的证据？
- [ ] 是否对负面信息给予了足够重视？

**修正方法**：强制阅读1-2篇看空观点的分析

---

### 3. 幸存者偏差

> 没有仅以过往成功倒推未来

**自查问题**：
- [ ] 是否仅参考了成功案例？
- [ ] 是否考虑了失败企业的共同特征？
- [ ] 是否用过去业绩线性外推未来？

**修正方法**：研究同行业失败案例，找出共性风险

---

### 4. 过度自信

> 没有对未来收益盲目乐观

**自查问题**：
- [ ] 增长预测是否过于乐观？
- [ ] 是否给了确定性过高的权重？
- [ ] 是否预留了安全边际？

**修正方法**：给出乐观/中性/悲观三种情景

---

### 5. 禀赋效应

> 没有因为持仓/个人偏好美化结论

**自查问题**：
- [ ] 是否因为持有该股票而美化分析？
- [ ] 是否因为个人喜好而忽视客观事实？
- [ ] 如果现在不持有，还会得出同样结论吗？

**修正方法**：假设自己是空仓，重新审视结论

---

## 边界提示

### 分析局限性

在报告中必须明确以下边界：

| 局限性 | 说明 |
|--------|------|
| 数据滞后 | 财务数据是历史信息，无法实时反映当前状况 |
| 会计估计 | 财务数据包含管理层判断，非绝对客观 |
| 信息不完整 | 公开信息可能不完整或被选择性披露 |
| 外部变量 | 宏观、行业变化无法完全预测 |
| 黑天鹅 | 极端事件无法通过常规分析预见 |

### 免责声明模板

```
⚠️ 边界提示

1. 本分析基于公开信息，可能存在信息不完整或滞后
2. 财务数据经过会计处理，包含管理层判断
3. 历史业绩不代表未来表现
4. 投资决策需动态跟踪，本分析仅为时点判断
5. 请结合自身风险承受能力做出决策
```
