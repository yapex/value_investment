## Narrative
### Structure
macOS Chinese input automation approach using clipboard and keyboard navigation

### Highlights
keystroke command only supports ASCII characters, so Chinese text must be pasted via clipboard. Search candidates are selected using arrow keys.

### Rules
Rule 1: Use clipboard for Chinese text input instead of keystroke
Rule 2: Use arrow keys (up/down) to navigate and select from search candidates
