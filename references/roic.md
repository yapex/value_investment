# ROIC (资本回报率) 计算说明

## 计算公式

```
ROIC = NOPAT / 平均投入资本
```

其中：
- **NOPAT** = 经营盈利 × (1 - 实际税率)
- **投入资本** = 权益总额 + 有息负债 - 现金及现金等价物
- **平均投入资本** = (当年投入资本 + 去年投入资本) / 2

## 参数说明

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `tax_rate` | 自动计算 | 税率，默认从财报中提取实际税率 |
| `use_avg_invested` | True | 是否使用2年平均投入资本 |

### 自定义参数示例

```bash
# 使用默认税率(25%)
v-invest indicator ROIC -s 00700 -m HK

# 指定税率
v-invest indicator ROIC -s 00700 -m HK --tax-rate 0.20

# 使用单年投入资本
v-invest indicator ROIC -s 00700 -m HK --use-avg-invested false
```

## 计算示例

腾讯 (00700) 2024年:

```
NOPAT = 经营溢利 × (1 - 税率)
      = 2,080.99亿 × (1 - 18.64%)
      = 1,693.05亿

投入资本(2024) = 总权益 - (现金 - 借款)
               = 10,538.96亿 - (4,030.97亿 - 3,386.15亿)
               = 9,894.14亿

投入资本(2023) = 8,736.81亿 - (3,876.04亿 - 1,973.56亿)
               = 6,183.43亿

平均投入资本 = (9,894.14 + 6,183.43) / 2 = 8,038.79亿

ROIC = 1,693.05 / 8,038.79 = 21.06%
```

## 与手工计算对比

| 年份 | 系统计算 | 手工计算 | 差异 |
|------|----------|----------|------|
| 2024 | 18.56% | 18.85% | 0.29% |
| 2023 | 12.84% | 14.5% | 1.66% |

差异主要来源：
1. 数据源微小差异(净现金口径)
2. 投入资本计算细节
