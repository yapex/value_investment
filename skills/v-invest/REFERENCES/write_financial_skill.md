# 如何编写财务分析 Skill

> 编写高质量财务分析 skill 的完整指南

---

## 概述

本文档介绍如何编写一个专业、可维护、高质量的财务分析 skill。它是"skill 的 skill"——帮助你构建其他财务分析 skill 的元技能。

---

## 1. 核心原则

### 1.1 数据原则

| 原则 | 说明 | 违反后果 |
|------|------|---------|
| **数据优先** | 所有数值必须来自 API 查询或计算 | 输出不可信 |
| **拒绝模糊** | 禁止使用"~"、"估"、"约"等表述 | 违反强制约束 |
| **可追溯** | 标注数据来源（v-invest/手动计算/待查询） | 无法验证 |

### 1.2 格式原则

| 原则 | 说明 |
|------|------|
| **结构化输出** | 表格 + 评级 + 结论 |
| **明确的评级** | 每个维度必须有 🟢/🟡/🔴 评级 |
| **行业对比** | 必须包含行业基准（即使标注待查询） |

### 1.3 完整性原则

| 检查项 | 要求 |
|--------|------|
| 时间跨度 | 必须覆盖 5 年数据（2020-2024） |
| 指标完整性 | 每个维度包含全部必需列 |
| 结论明确 | 不能只有数据，必须有分析结论 |

## 3. 数据获取策略

### 3.1 分层数据获取

```
┌─────────────────────────────────────────────┐
│  第1层: 快速获取 (CLI)                      │
│  v-invest indicator "roe,roa" -s {code}    │
├─────────────────────────────────────────────┤
│  第2层: 完整数据 (Python API)               │
│  vi.get_profit_sheet()                     │
├─────────────────────────────────────────────┤
│  第3层: 计算衍生指标                        │
│  费用率 = 费用 / 营收                       │
└─────────────────────────────────────────────┘
```

### 3.2 指标可用性检查

在编写 skill 之前，必须验证指标可用性：

```python
# 指标可用性检查脚本
from value_investment import ValueInvestment

vi = ValueInvestment()
available = vi.list_indicators()

# 检查目标指标
test_indicators = ['roe', 'ROIC', 'debt_ratio']
for ind in test_indicators:
    try:
        df = vi.get_indicator_history(ind, '000001', years=1)
        print(f"{ind}: {'✅' if not df.empty else '⚠️ 空数据'}")
    except:
        print(f"{ind}: ❌ 不可用")
```

### 3.3 常见问题与解决

| 问题 | 解决方式 |
|------|---------|
| 指标返回空 | 尝试不同大小写（如 ROIC vs roic） |
| 缺少字段 | 从财务报表手动计算 |
| 数据不连续 | 过滤 end_type='4' 取年报 |

## 4. 输出格式设计

### 4.1 表格设计规范

```markdown
| 年份 | 营业收入 | 净利润 | 评级 |
|------|---------|--------|------|
| 2024 | 1500.00 | 775.23 | 🟢优秀 |
| 2023 | 1476.94 | 747.34 | 🟢优秀 |
```

**规范要点**：
- 数值保留 2 位小数
- 单位明确标注（亿元/%/倍）
- 包含年份连续性检查

### 4.2 评级系统

| 评级 | 定义 | 触发条件 |
|------|------|---------|
| 🟢 优秀/顶尖 | 显著优于行业 | 指标 > 行业平均 50%+ |
| 🟡 良好/一般 | 符合行业平均 | 指标 ≈ 行业平均 |
| 🔴 较差 | 显著低于行业 | 指标 < 行业平均 50%+ |

### 4.3 结论模板

```markdown
**{维度名称}评级**：🟢{评级}

- {分析点1}
- {分析点2}
- {分析点3}
```

## 5. 校验机制

### 5.1 自检清单

```markdown
## 校验清单

### 数据完整性
- [ ] 所有年份（2020-2024）数据完整
- [ ] 无"~"、"估"、"约"等模糊表述
- [ ] 自由现金流已计算

### 格式完整性
- [ ] 每个维度表格完整
- [ ] 每个维度有🟢/🟡/🔴评级
- [ ] 汇总表包含全部维度

### 内容完整性
- [ ] 营收维度含 OCF、FCF
- [ ] 成本维度含 5 年费用率
- [ ] 增长维度含 CAGR + 行业对比
```

### 5.2 自动化校验脚本

```python
# 校验脚本示例
def validate_output(content: str) -> dict:
    issues = []
    
    # 检查模糊数据
    fuzzy_patterns = ['~', '估', '约', '大概']
    for pattern in fuzzy_patterns:
        if pattern in content:
            issues.append(f"发现模糊数据: {pattern}")
    
    # 检查评级
    if '🟢' not in content and '🟡' not in content and '🔴' not in content:
        issues.append("缺少评级符号")
    
    # 检查年份
    for year in ['2020', '2021', '2022', '2023', '2024']:
        if year not in content:
            issues.append(f"缺少年份: {year}")
    
    return {
        'valid': len(issues) == 0,
        'issues': issues
    }
```

## 6. 行业特性处理

### 6.1 行业调整清单

| 行业 | 特性指标 | 调整说明 |
|------|---------|---------|
| 白酒 | 存货周转天数 | 1000-1500天为正常（非负面） |
| 制造业 | 固定资产占比 | 需考虑产能利用率 |
| 互联网 | 用户数/ARPU | 关注增长指标 |
| 银行 | 净息差 | 关注不良率 |

### 6.2 行业数据来源

```markdown
### 行业基准获取

1. **内建参考值**（常见行业）
   - 白酒毛利率：60-70%
   - 制造业 ROE：10-15%

2. **外部查询**
   - 同花顺行业平均
   - 理杏仁行业数据

3. **标注待查询**
   > ⚠️ 行业数据待查询
```

## 8. 最佳实践

### 8.1 编写技巧

| 技巧 | 说明 |
|------|------|
| **先验证再编写** | 确认指标可用再写入文档 |
| **提供可运行代码** | Python 代码可直接复制使用 |
| **示例数据具体** | 用真实公司示例，避免占位符 |
| **版本标注** | 标注 v-invest 版本要求 |

### 8.2 常见错误

| 错误 | 后果 | 避免方式 |
|------|------|---------|
| 占位符未替换 | 用户无法直接使用 | 提供真实示例 |
| 命令过时 | 执行失败 | 测试验证 |
| 格式不一致 | 输出混乱 | 严格模板 |
| 缺少校验 | 质量不可控 | 添加清单 |
