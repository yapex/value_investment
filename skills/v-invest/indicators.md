# 指标体系

## 计算指标

| 指标 | 说明 | 公式 | 市场 |
|------|------|------|------|
| `ROE` | 净资产收益率 | 净利润 / 股东权益 | A股/港股 |
| `ROA` | 总资产收益率 | 净利润 / 总资产 | A股/港股 |
| `gross_margin` | 毛利率 | (营收 - 成本) / 营收 | A股/港股 |
| `net_profit_margin` | 净利率 | 净利润 / 营收 | A股/港股 |
| `current_ratio` | 流动比率 | 流动资产 / 流动负债 | A股/港股 |
| `quick_ratio` | 速动比率 | (流动资产 - 存货) / 流动负债 | A股/港股 |
| `debt_ratio` | 资产负债率 | 总负债 / 总资产 | A股/港股 |
| `asset_turnover` | 资产周转率 | 营业收入 / 总资产 | A股/港股 |
| `inventory_turnover` | 存货周转率 | 营业成本 / 存货 | A股/港股 |
| `receivable_turnover` | 应收周转率 | 营业收入 / 应收账款 | A股/港股 |
| `payable_turnover` | 应付周转率 | 营业成本 / 应付账款 | A股 |
| `cfo_to_netprofit_sum` | 净利润含金量（累计净现比） | 经营现金流累计 / 净利润累计 | A股/港股 |
| `ROIC` | 投资资本回报率 | NOPAT / 投入资本 | A股/港股 |
| `CAGR` | 复合增长率 | (终值/初值)^(1/年数)-1 | A股/港股 |
| `ImpliedGrowth` | 市场隐含增长率 | 基于DCF模型反推 | A股/港股 |
| `PEPct` | PE历史百分位 | 当前PE在历史PE序列中的位置 | A股/港股 |
| `latest_market_cap` | 最新市值 | 最新收盘价 × 已发行股本 | A股/港股 |
| `PE` | 市盈率 | 市值 / 净利润 | A股/港股 |
| `PB` | 市净率 | 市值 / 股东权益 | A股/港股 |
| `market_cap` | 总市值 | 股票总市值 | A股/港股/美股 |

## 指标详情

### ROIC (投资资本回报率)

- 公式: `NOPAT / 投入资本`
- 投入资本 = 股东权益 + 有息负债 - 现金
- 支持港股实际税率自动计算
- 默认使用2年平均投入资本

### CAGR (复合增长率)

- 支持指标: `revenue`, `net_profit`, `total_assets`, `total_equity`
- 参数: `metric="revenue"` 或 `metric="net_profit"`

### ImpliedGrowth (市场隐含增长率)

- 基于DCF模型反推增长率
- 参数: `wacc` (加权平均资本成本，默认10%), `growth_rate` (永续增长率，默认3%)
- 自动获取最新市值

### PEPct (PE历史百分位)

- 通过历年末股价 × 当时股本 / 当时净利润计算历史PE
- 与当前PE比较计算百分位
- 参数: `years` (历史年份数，默认10)

### latest_market_cap (最新市值)

- 通过最新收盘价(不复权) × 已发行股本计算
- 用于需要最新市值的指标

## PE/PB 计算

- **PE** = 最新市值 / 净利润（最新报告期）
- **PB** = 最新市值 / 股东权益

## 使用注意事项

- PEPct 使用不复权股价计算，上市初期PE可能失真
- 适用于成熟期公司，新股/周期股需谨慎
