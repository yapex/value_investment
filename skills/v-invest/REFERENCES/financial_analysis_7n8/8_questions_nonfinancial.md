# 八问非财务分析

定性分析，基于收集到的信息逐一回答八个核心问题。

## 工作流程

### Step 1: 信息收集

使用浏览器工具收集非财务信息：

- 券商深度研报（2篇近期）
- 招股书（如有）
- 创始人/管理层访谈
- 行业研究报告
- 近期新闻动态

### Step 2: 逐一回答八问

每个问题需给出明确结论，并标注信息来源。

---

## 1️⃣ 生意模式

> 核心问题：靠什么赚钱？盈利逻辑是什么？

### 分析要点

| 分析项 | 说明 |
|--------|------|
| 收入来源 | 产品/服务销售、订阅、广告、佣金等 |
| 客户类型 | To B / To C / To G |
| 盈利逻辑 | 如何创造价值、捕获价值 |
| 商业模式 | 平台、直销、代理、订阅等 |

### 输出模板

```
生意模式：{一句话描述}
客户类型：{To B/C/G}
盈利逻辑：{核心赚钱方式}
信息来源：{来源标注}
```

---

## 2️⃣ 外部环境

> 核心问题：行业处于什么周期？政策态度如何？

### 分析要点

| 分析项 | 关注点 |
|--------|--------|
| 行业周期 | 上行期 / 下行期 / 成熟期 |
| 政策环境 | 支持 / 中性 / 限制 |
| 宏观影响 | 经济周期敏感度 |
| 监管趋势 | 趋严 / 放松 / 稳定 |

### 输出模板

```
行业周期：{上行/下行/成熟}
政策态度：{支持/中性/限制}
宏观敏感度：{高/中/低}
信息来源：{来源标注}
```

---

## 3️⃣ 行业空间

> 核心问题：市场有多大？增长潜力如何？

### 分析要点

| 分析项 | 说明 |
|--------|------|
| 当前市场规模 | TAM（总可触达市场） |
| 未来3-5年CAGR | 行业增速预测 |
| 增长驱动因素 | 什么推动行业增长 |
| 天花板判断 | 市场饱和度 |

### 输出模板

```
当前市场规模：{数值} 亿元
未来5年CAGR：{x}%
增长驱动：{核心驱动因素}
天花板判断：{远/中/近}
信息来源：{来源标注}
```

---

## 4️⃣ 竞争格局

> 核心问题：行业竞争激烈程度如何？

### 分析要点

| 分析项 | 关注点 |
|--------|--------|
| 行业集中度 | CR3 / CR5 |
| 头部企业份额 | 龙头市占率 |
| 竞争激烈程度 | 价格战、营销战等 |
| 进入壁垒 | 新玩家进入难度 |

### 输出模板

```
行业集中度：{高/中/低}，CR3={x}%
公司市占率：{x}%，排名第{x}
竞争强度：{激烈/一般/温和}
进入壁垒：{高/中/低}
信息来源：{来源标注}
```

---

## 5️⃣ 护城河

> 核心问题：核心竞争优势是什么？能否持续？

### 护城河类型

| 类型 | 说明 | 案例 |
|------|------|------|
| 品牌 | 溢价能力、用户心智 | 茅台、苹果 |
| 技术 | 专利、研发壁垒 | 华为、台积电 |
| 成本 | 规模效应、供应链 | 沃尔玛、宁德时代 |
| 网络 | 用户网络效应 | 微信、美团 |
| 转换成本 | 迁移难度 | 企业软件 |
| 特许经营 | 牌照、资质 | 金融、烟草 |

### 输出模板

```
核心优势：{品牌/技术/成本/网络/转换成本/特许}
优势强度：{宽/窄/无}
可持续性：{强/中/弱}
复制难度：{高/中/低}
信息来源：{来源标注}
```

## 6️⃣ 管理层

> 核心问题：管理层能力与诚信如何？

### 分析要点

| 分析项 | 关注点 |
|--------|--------|
| 创始人背景 | 创业经历、行业经验 |
| 战略执行力 | 过往承诺兑现情况 |
| 资本配置 | 并购、回购、分红决策 |
| 诚信记录 | 是否有违规、诉讼 |

### 输出模板

```
核心人物：{姓名}，{职位}
能力评价：{强/中/弱}
诚信记录：{无问题/有关注点}
过往执行力：{优秀/一般/较差}
信息来源：{来源标注}
```

## 7️⃣ 风险因素

> 核心问题：最核心的3个风险是什么？

### 风险分类

| 类别 | 示例 |
|------|------|
| 行业风险 | 周期下行、技术替代 |
| 竞争风险 | 价格战、新进入者 |
| 政策风险 | 监管趋严、牌照风险 |
| 经营风险 | 客户集中、供应链 |
| 财务风险 | 高负债、现金流 |

### 输出模板

```
风险1（{类别}）：{描述}，影响程度：{高/中/低}
风险2（{类别}）：{描述}，影响程度：{高/中/低}
风险3（{类别}）：{描述}，影响程度：{高/中/低}
信息来源：{来源标注}
```

## 8️⃣ 未来展望

> 核心问题：未来1-3年增长驱动是什么？

### 分析要点

| 分析项 | 关注点 |
|--------|--------|
| 增长驱动 | 新产品、新市场、提价等 |
| 发展路径 | 是否清晰可执行 |
| 管理层指引 | 业绩目标、战略规划 |
| 催化剂 | 可能的股价/业绩催化剂 |

### 输出模板

```
增长驱动：{核心驱动因素}
路径清晰度：{清晰/一般/模糊}
管理层指引：{有/无}，{具体内容}
潜在催化剂：{列举}
信息来源：{来源标注}
```
