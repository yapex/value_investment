# ROE 深入分析

15+ 指标 + 10年历史数据，全面评估。适合深度研究。

## 工作流程

### Step 1: 获取核心指标数据

执行以下 CLI 命令获取 10 年历史数据：

```bash
# 杜邦三要素 + 盈利能力
v-invest indicator "roe,roa,net_profit_margin,gross_margin,total_assets_turnover,equity_multiplier" -s {股票代码} -m {市场} -y 10
```

### Step 2: 获取财务指标快照

```bash
# 财务指标（当前值）
v-invest finind {股票代码} -m {市场}
```

### Step 3: 按框架分析

根据获取的数据，按照以下框架进行分析：

1. **稳定性评估**: 计算 10年平均ROE、变异系数、偏离度
2. **杜邦拆解**: 分析净利润率、周转率、权益乘数的贡献
3. **驱动因素**: 判断是利润驱动、周转驱动还是杠杆驱动
4. **财务结构**: 评估资产负债率、流动比率等
5. **现金流**: 评估经营现金流覆盖能力

### Step 4: 输出报告

按照下方模板格式整理成 Markdown 报告。

## 分析框架

### 1. ROE 历史趋势分析（10年）

#### 稳定性评估

| 评估项 | 方法 | 优秀标准 |
|--------|------|---------|
| 10年平均 ROE | 均值 | >15% |
| ROE 标准差 | 波动性 | 越小越稳定 |
| 变异系数 | 标准差/均值 | <0.2 稳定 |
| 正收益年份占比 | ROE>0 年份/10 | >90% |

#### 穿越周期能力

- 经济下行期 ROE 表现
- 行业低谷期是否保持正值
- 与宏观经济指标相关性

#### 均值回归检验

- 偏离度 = (当前 ROE - 10年均值) / 10年均值
- 偏离度 > 20%: 可能高估
- 偏离度 < -20%: 可能低估

### 2. 杜邦拆解

```
ROE = 净利润率 × 总资产周转率 × 权益乘数
```

#### 驱动因素识别

| 驱动类型 | 特征 | 代表企业 |
|----------|------|---------|
| 高净利率 | 茅台、苹果 | 品牌溢价 |
| 高周转率 | 沃尔玛、亚马逊 | 运营效率 |
| 高杠杆 | 金融、地产 | 财务杠杆 |

#### 10年演变趋势

分析三要素的历史变化，判断驱动因素是否可持续。

### 3. 盈利能力分析

| 指标 | 说明 |
|------|------|
| roe_weighted | 净资产收益率(加权) |
| net_profit_margin | 净利润率 |
| gross_margin | 毛利率 |
| operating_profit_margin | 营业利润率 |

### 4. 运营效率分析

| 指标 | 说明 |
|------|------|
| asset_turnover | 总资产周转率 |
| inventory_turnover | 存货周转率 |
| receivables_turnover | 应收账款周转率 |

### 5. 财务结构分析

| 指标 | 说明 | 关注点 |
|------|------|--------|
| debt_ratio | 资产负债率 | <60% 稳健 |
| equity_multiplier | 权益乘数 | 因行业而异 |
| current_ratio | 流动比率 | >1.5 稳健 |
| quick_ratio | 速动比率 | >1.0 稳健 |

### 6. 现金流分析

| 指标 | 说明 | 优秀标准 |
|------|------|---------|
| operating_cashflow_to_debt | 经营现金流/总负债 | >50% |
| free_cashflow_to_netprofit | 自由现金流/净利润 | >80% |

## 输出模板

按以下结构整理报告：

### 一、ROE 概览

- 当前值、10年均值、10年最高/最低
- 趋势判断（上升/下降/平稳）

### 二、10年历史趋势

- ROE 走势表（年份、ROE、同比变化）
- 稳定性评估（变异系数、正收益年份）
- 均值回归检验（偏离度）

### 三、杜邦拆解

- 公式：ROE = 净利润率 × 总资产周转率 × 权益乘数
- 驱动因素识别（利润驱动/周转驱动/杠杆驱动）
- 可持续性评估

### 四、财务结构分析

- 资产负债率、流动比率、速动比率

### 五、现金流分析

- 经营现金流/负债比率

### 六、风险提示

- 主要风险点

### 七、投资结论

- 综合评分
- 核心观点
