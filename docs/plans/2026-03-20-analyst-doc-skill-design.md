# 分析师文档 Skill 设计

> **日期**: 2026-03-20
> **状态**: 设计完成

---

## 1. 概述

### 1.1 目标

创建 **value-forge**（Meta Skill），用于将分析师文档转化为可执行的分析技能。

### 1.2 设计原则

- **人工提取字段**：直接阅读文档，不使用脚本解析
- **默认10年数据**：长期分析需要充足历史数据
- **通用性**：适用于任何分析师文档

---

## 2. value-forge 工作流程

```
用户: "帮我把 docs/企业财务排雷手册.md 创建为 skill"
         ↓
Agent 阅读文档，人工提取字段
         ↓
创建 .pi/skills/{skill-name}/
         ↓
生成 SKILL.md + REFERENCE.md
```

### Step 1: 阅读文档
- 直接读取 markdown 文件
- 人工识别需要的字段（查看表格"使用字段"列）
- 按数据类型分组整理

### Step 2: 提取字段
```markdown
### 利润表字段
- total_revenue, operating_cost, net_profit, ...

### 资产负债表字段
- total_assets, total_liabilities, ...

### 财务指标
- roe, gross_margin, debt_ratio, ...
```

### Step 3: 生成 Skill
```bash
mkdir -p .pi/skills/{skill-name}
```

### Step 4: SKILL.md 模板
```markdown
---
name: {skill-name}
description: {描述}
---

# {标题}

## 数据获取（默认10年）
v-invest query {股票} -r "{字段}" -e {年份} -y 10

## 执行
读取 REFERENCE.md，按文档格式输出报告。
```

---

## 3. 字段提取指南

### 常见模式

| 文档格式 | 提取方式 |
|---------|---------|
| `**需要字段**: xxx` | 直接提取 |
| `| 字段 | 使用字段 | ...` | 读取第二列 |
| `| 指标 | 公式 | ...` | 根据指标推断 |

### 注意事项

1. **不要用脚本**：每个文档格式不同，脚本难以通用
2. **关注表格**：通常在表格中声明字段
3. **字段分组**：按数据类型（利润表/资产负债表/现金流量表/指标）整理
